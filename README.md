# Onflix

A first React project inspired by Netflix's profile-selection screen. It lets visitors view, add, and update user profiles.

**Live site:** [onchetrit.github.io/Onflix](https://onchetrit.github.io/Onflix/)

## Tech

React loaded in the browser, HTML, CSS, and local storage.

## Run locally

~~~bash
python3 -m http.server 8080
~~~

Then open http://localhost:8080.
